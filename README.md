# Conteo y Pedido

App para el conteo de lunes y jueves y el armado del pedido para cubrir dos ciclos.

- Abrila desde GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
- Los datos **no** se guardan acá: se guardan en el repositorio privado `conteo-pedido-datos`. Al entrar, la app pide ese repositorio y un token de GitHub con permiso *Contents: Read and write* solo sobre él.
